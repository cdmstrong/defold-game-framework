- `assets/fonts/zh.font` + `assets/fonts/ArialUnicode.ttf` — 中文字体资源（SDF 距离场），字符集覆盖 Demo 中文文案 + ASCII。
- `tests/lua/` — 纯 Lua 单测（harness + test_save + test_services），25 个用例。
- `scripts/check-m3.mjs` — HTML5 集成验证脚本（存档跨刷新、语言切换、截图）。
- `examples/ui_demo/` — bootstrap 接入四个服务，Settings 页加音量（音乐/音效 +/-）、静音、语言切换；`l10n.lua` 中英文案。

## 修复与关键结论

1. **`sys.save` 路径必须来自 `sys.get_save_file`**：初始用硬编码 `/framework_save/primary`，HTML5 下 `sys.save` 报「Could not write to the file」。改用 `sys.get_save_file(app_id, slot)` 后，HTML5 正确落 IndexedDB 并跨刷新恢复。
2. **Defold `msg.post` 不能可靠传递负数浮点字段**：`send("volume", { delta = -0.1 })` 里 `delta` 到达接收方变成 `nil`（`group` 字符串字段正常）。改用独立消息 id（`volume_down`/`volume_up`），由接收方按消息 id 决定增量方向，绕开负数传递。
3. **`.font` 的 `characters` 字符串需转义引号/反斜杠**：初始把 ASCII 32–126 整段塞进 `characters`，其中 `"` 与 `\` 未转义导致字符串提前终止，后续 ASCII 字符（+/-、数字、大写字母）全部丢失，中文因排在前面反而正常。去除 `"`/`\` 后 ASCII 与中文均完整。
4. **存储接口统一点调用语义**：`storage`/`settings` 的适配器与测试后端统一为无隐式 self 的纯函数，`save_manager` 与 `settings` 均用 `.` 调用，避免 `:`/`.` 混用导致的参数错位。

## 界限

- `Storage.defold` 只承诺同步后端；异步后端需另设契约（见 API 合约）。
- 音频 `backend` 在 Demo 中为无声音资源的记录式空实现，验证解锁与分组逻辑，不验证真实混音输出。
- 中文字体字符集仅覆盖 Demo 文案（115 字符），非全字库；生产需按游戏文案扩展字符集。
- 双槽恢复用真实无效数据（缺 `payload` 字段、非法 envelope）验证，未做物理磁盘损坏级测试。
