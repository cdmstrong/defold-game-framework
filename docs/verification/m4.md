# M4 验证记录

日期：2026-11-18（Asia/Shanghai）。环境：本机 macOS / Apple Silicon，Defold 与 Bob 1.14.1，engine SHA `ee283d4dad9fa451dd6399d83602e1dc25133681`，Lua 5.5.1（纯 Lua 单测运行器）。

M4 边界：平台与广告抽象——平台检测（browser/desktop/mobile）、激励视频广告门面（可配置 taptap/233 乐园/mock/none）、幂等发奖、看门狗、busy 重入、广告期间暂停主循环、Analytics 埋点。参考 cocos-template 的 `assets/ads` 架构（AdTypes + RewardAdService 门面 + IAdProvider 接口 + 多 provider + AdLogger + 平台解析），按 Defold 纯 Lua 可测约定落地。

## 产物

- `framework/platform/ad_types.lua` — 状态码（`AD_STATUS`，0/3 过程态、4 奖励态）、原因枚举、平台展示名、`is_known_platform`。
- `framework/platform/ad_logger.lua` — 环形缓冲日志（80 条上限）、可关 verbose、`log/warn/error/get_entries/clear`。
- `framework/platform/platform.lua` — 平台检测：`sys.get_sys_info().system_name` 判断 `HTML5/Emscripten → browser`、`Darwin/Windows/Linux → desktop`、`Android/iPhone OS → mobile`；支持 `override` 注入。
- `framework/platform/reward_ad.lua` — 激励视频门面（业务唯一入口）：`init/is_supported/show_rewarded/grant_once/was_granted/on_ad_open/on_ad_close/set_platform/get_platform_id/get_diagnostics`。含 `false` 短 TTL 缓存（30s）、busy 重入保护、看门狗兜底超时、`grant_once` 幂等（发奖失败回滚）。
- `framework/platform/providers.lua` — provider 注册表：`register_provider/has_provider/create_provider`，未知平台回落 `none`。
- `framework/platform/providers/none.lua` — 无广告 provider，`is_supported` 恒 false。
- `framework/platform/providers/mock.lua` — 模拟 provider，非交互环境延迟 1s 返回 rewarded，可 `set_chooser` 注入结果。
- `framework/platform/providers/leyuan.lua` — 233 乐园 MetaH5Ad provider：动态加载 SDK、`isAdSupport`/`showAd`、回调归一化（code/status/isRewarded）、过程态 0/3 继续等待、仅 status=4 发奖。
- `framework/platform/providers/taptap.lua` — TapTap 小游戏 provider：`tap.createRewardedVideoAd({adUnitId})`、`show()` + `onClose(res.isEnded)`、`onError`/`onLoad`、素材未就绪 `load()` 后重试。
- `framework/analytics/analytics.lua` — 埋点：`track(event, params)` 落注入 logger（默认 print），带 seq/时间戳，`flush` 钩子。
- `tests/lua/test_platform.lua` — 纯 Lua 单测 23 用例。
- `scripts/check-m4.mjs` — HTML5 集成验证（平台检测、mock 广告 rewarded、grant_once 幂等）。
- `examples/ui_demo/` — bootstrap 接入 platform/reward_ad/analytics 三服务（广告平台由 `m4.ad_platform` 配置，默认 mock），components 页加「WATCH AD」按钮，`on_ad_open/close` 对接 `pause:acquire("ad")`。

## 修复与关键结论

1. **Defold 平台检测 API 是 `sys.get_sys_info()`，不是 `sys.get_engine_info()`**：初版用错 API 导致 `kind=unknown system=unknown`。正确字段 `system_name`，HTML5 下为 `"HTML5"`（旧引擎 `"Emscripten"`），桌面为 `Darwin/Windows/Linux`，移动为 `Android/iPhone OS`。
2. **Defold HTML5 的 `html5.run` 是全局函数，不在 `sys.html5` 下**：js 执行器需通过 `options.html5` 显式注入（bootstrap 传入全局 `html5` 模块），而非从 `sys.html5.run` 探测。桌面/原生无 `html5` 时返回 nil，provider 判为 unsupported。
3. **mock 广告在 Defold 里无 DOM**：不弹 DOM 选择框，直接延迟后返回 rewarded（`set_chooser` 可注入自定义结果），保证业务流程在无 DOM 环境可跑通。
4. **广告期间暂停主循环通过门面事件对接 pause**：`on_ad_open → pause:acquire("ad")`，`on_ad_close → release`，与 M1 的引用计数 pause 复用，不重复实现暂停逻辑。

## 界限

- **taptap / 233（leyuan）provider 仅实现 H5/小游戏宿主注入全局对象（`tap` / `window.MetaH5Ad`）路径**：真实广告需在对应平台宿主内运行（`ad_unit_id` 由 `m4.ad_unit_id` 配置，233 SDK 地址由 `m4.leyuan_sdk_url` 配置）。本机 HTML5 集成用 mock 验证状态机，未在真实 TapTap / 233 宿主内跑通真实广告（需平台开发者账号与广告位）。
- **js 执行器是同步读取 `window.__ad_result__` 的约定**：`html5.run` 在 Defold 中同步执行 JS，provider 的 JS 需同步把终态写入 `window.__ad_result__`（Lua 无 Promise，异步回调由 JS 内部消化后同步回传）。
- **Analytics 默认 logger 是 print**：真实上报通道（TapDB、自建后端）由使用方注入。
- 看门狗语义在纯 Lua 侧为「provider 内部遵守 timeout_ms」，门面不二次计时（避免纯 Lua 测试复杂化）；真实 SDK 超时由 provider JS 内的 `setTimeout` 兜底。

## 配置说明（打包前改）

| 配置键 | 默认 | 说明 |
|---|---|---|
| `m4.ad_platform` | `mock` | 目标广告平台：`taptap` / `leyuan` / `mock` / `none` |
| `m4.ad_unit_id` | 空 | TapTap 激励视频广告位 id（`leyuan` 用固定 adType=1，不需此项） |
| `m4.leyuan_sdk_url` | `https://cdn.233xyx.com/h5ad/metah5ad_v1.min.js` | 233 乐园 MetaH5Ad SDK 地址 |

- 233 乐园（H5）：`m4.ad_platform = 'leyuan'`
- TapTap 小游戏：`m4.ad_platform = 'taptap'` 并填 `m4.ad_unit_id`
- 无广告版本（审核/单机）：`m4.ad_platform = 'none'`
- 本地跑通流程：`m4.ad_platform = 'mock'`（默认）
